# ecoaxl_bot

Telegram-система заказов для сервиса по подписке: клиент выбирает тариф, оформляет заказы, а исполнитель берёт заказ и закрывает его фото-отчётом.

## Что делает
**Бот клиента**
- Регистрация с выбором языка (RU/UZ), телефон, район и адрес с геолокацией
- Выбор тарифа и оплата прямо в Telegram
- Создание заказа с фото и комментарием, управление профилем
- Плановые напоминания и рассылки от администратора

**Бот исполнителя**
- Регистрация и выбор района
- Список доступных заказов, взятие заказа в работу, завершение с фото

**Админ-панель** (Django admin): тарифы, районы, клиенты, исполнители, заказы

## Стек
Python, aiogram 3 (FSM), APScheduler, Django 4 + DRF, django-jazzmin, PostgreSQL, gunicorn, Docker Compose

## Архитектура
```
 client_bot ─┐                      ┌─► PostgreSQL
             ├─ HTTP (токен) ─► Django REST API ──► Django admin (Jazzmin)
 worker_bot ─┘
```
- Два независимых aiogram-бота; вся бизнес-логика и данные — в одном Django REST-бэкенде.
- Бэкенд авторизует ботов отдельными токенами (клиент / исполнитель).
- Сценарии диалога — группы состояний FSM (регистрация → тариф → оплата → адрес → заказ).
- Локализация — каталог сообщений плюс язык, сохранённый у пользователя.
- Платежи через Telegram Payments (инвойс, pre-checkout, successful payment).
